NAS-Backup

NAS-Backup 是由 Lokous 管理的個人 OAuth 用戶端設定，使用開源工具 Rclone 在自己的 Windows 電腦上將 NAS 檔案備份至自己的 Google Drive，並進行完整性檢查及還原。

運作方式

使用者在本機執行 Rclone，透過 Google OAuth 2.0 授權後，直接與 Google Drive API 通訊。本網站僅提供說明，不提供登入、檔案上傳或遠端備份服務，不會接收備份資料或 OAuth 憑證。

使用範圍

僅供管理者個人使用，不對外提供商業服務。備份採單向複製，預定使用不可覆寫模式；實際操作取決於本機指令設定。

About this application

NAS-Backup is a personal OAuth client configuration operated by Lokous. Rclone runs on the operator’s own Windows computer to copy NAS files to the operator’s Google Drive, verify backups and restore files. This static website does not receive files or OAuth credentials. It is not a public backup service.
